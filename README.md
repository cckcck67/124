# VR 網頁播放器 (Android)

把網頁影片畫面切成左右兩份,放進 VR 盒子觀看。

## 架構
網頁 WebView → 私有虛擬螢幕 (VirtualDisplay + Presentation) → OpenGL 材質
→ 2D 模式畫一份 / VR 模式左右各一份(大小、位置、間距、翻轉角度可調)

## 操作
**2D 模式(一開始)**:像一般瀏覽器用手指操作。上方輸入網址或關鍵字,
`yt 關鍵字` 直接搜尋 YouTube。網址列平常收起,不擋網頁:
網頁已在最上面時,再用手指往下拉一次才會出現;往下捲或輸入新網址後自動收起。
網址列的「★」= 書籤:點一下開啟、「加入目前網頁」收藏、長按可改名稱 / 網址或刪除。
點網頁裡的文字框(例如 YouTube 搜尋框)會跳出輸入視窗,可用手機鍵盤打字。

**設定**(網址列右邊的按鈕):打開後只顯示滑桿,下方直接預覽 VR 畫面,數值會記住;
按「完成」或返回鍵關閉
- 畫面大小:平面模式的放大倍率,越大越填滿視野(邊緣會被裁掉)
- 畫面高低:往右 = 畫面往上移(VR 盒子下緣通常比較看不到)
- 左右間距:往左 = 兩眼畫面往中間靠(預設依手機螢幕寬度自動計算)
- 翻轉角度:兩眼畫面沿垂直軸往相反方向翻轉;太大容易頭暈
- VR視野:VR180 模式看到的範圍,配合 VR 盒子鏡片調到景物大小自然
- 面板距離:面板出現雙影時調整,往右 = 面板看起來較近
- 中間空隙(平面) / 中間空隙(VR180):兩眼畫面中間的黑色空隙,避免看到另一邊畫面造成雙影
  (預設平面 0.1、VR180 / 上下VR 0.03)

**VR 模式**:控制面板和紅點游標依姿勢叫出,頭轉回正前方就收起來
- 坐姿:低頭約 50 度叫出,面板在下方
- 躺平:抬頭約 25 度叫出,面板在上方
- 面板由靠近畫面中央往外:空白列(紅點從這裡開始)→ 進度條 → 按鈕 → 資訊列
- 按鈕:坐姿/躺平 / 音量－ / 音量＋ / 快進10秒 / 速度 / 模式 / 置中,看著約 1.2 秒觸發
- 坐姿/躺平:切換後自動開始置中倒數,倒數時看著新姿勢的正前方
- 音量、快進10秒持續看著會一直重複
- 「速度」「模式」會在上方拉出選項,往上看著想要的選項即可選取;
  選項拉出時其他按鈕暫停作用,再看一次原本的按鈕可收起
- 置中:觸發後畫面正中央倒數 3、2、1,倒數時抬頭看想要的正前方,
  數完就以那個方向為準(躺著看天花板也可以)
  - 速度:0.5x / 1x / 1.5x
  - 模式(會記住):

| 模式 | 用途 |
|---|---|
| 2D | 一般影片 / 網頁 |
| 左右3D | 左右並排的 3D 影片(YouTube 搜尋「3D SBS」) |
| VR180 | 左右兩個半球的 VR 影片,轉頭可上下左右看,真正立體 |
| 上下VR | 上下兩個攤平全景圖的 VR 影片(上半給左眼),轉頭可上下左右看,真正立體 |

- 2D 模式看整個網頁;其他模式會自動找出網頁中的影片,只顯示影片本身
- 沒開面板時,點一下螢幕 = 播放 / 暫停
- 長按 = 立刻把目前方向設為正前方(同「置中」,不用倒數)
- 返回鍵 = 回到 2D 模式

**藍牙遙控器 / 搖桿(VR 模式)**
- 左 / 右:倒退 / 快進 10 秒
- 播放鍵:播放 / 暫停;中鍵 / A:同點一下螢幕(面板打開時 = 選取看著的項目)
- 上 / 下:音量

## 編譯
方法 A:GitHub Actions(不用裝 Android Studio)— 上傳整個資料夾到 GitHub,
Actions 會自動編譯,在 Artifacts 下載 APK。
方法 B:Android Studio 開啟此資料夾 → Build → Build APK(s)。

## 已知限制
- 網頁文字框要在 2D 模式點,VR 模式中無法打字
- 控制面板直接控制網頁中的影片;少數把影片放在內嵌框架中的網站會改用模擬點擊
- Netflix 等 DRM 影片會是黑畫面
- Google 帳號登入在 WebView 會被擋
