# VR 網頁播放器 (Android)

把網頁影片畫面切成左右兩份,放進 VR 盒子觀看。

## 架構
網頁 WebView → 私有虛擬螢幕 (VirtualDisplay + Presentation) → OpenGL 材質
→ 2D 模式畫一份 / VR 模式左右各一份(大小、位置、間距、翻轉角度可調)

## 操作
**2D 模式(一開始)**:像一般瀏覽器用手指操作。上方輸入網址或關鍵字,
`yt 關鍵字` 直接搜尋 YouTube。網址列只在網頁捲到最上面時出現。
點網頁裡的文字框(例如 YouTube 搜尋框)會跳出輸入視窗,可用手機鍵盤打字。

**設定**(網址列右邊的按鈕):打開後下方直接預覽 VR 畫面,數值會記住
- 畫面大小:平面模式的放大倍率,越大越填滿視野(邊緣會被裁掉)
- 畫面高低:往右 = 畫面往上移(VR 盒子下緣通常比較看不到)
- 左右間距:往左 = 兩眼畫面往中間靠(預設依手機螢幕寬度自動計算)
- 翻轉角度:兩眼畫面沿垂直軸往相反方向翻轉;太大容易頭暈
- VR視野:VR180 / YouTube 360 模式看到的範圍,配合 VR 盒子鏡片調到景物大小自然
- 兩眼中間固定留 0.1 的黑色空隙,避免雙影

**VR 模式**(面板上的「模式」按鈕切換,會記住)
| 模式 | 用途 | 面板開關 |
|---|---|---|
| 2D | 一般影片 / 網頁 | 低頭約 30 度 |
| 左右3D | 左右並排的 3D 影片(YouTube 搜尋「3D SBS」) | 低頭約 30 度 |
| VR180 | 左右兩個半球的 VR 影片,轉頭可上下左右看,真正立體 | 點一下螢幕 |
| YT 360 | YouTube 的 360 / VR 影片,轉頭可上下左右看(兩眼同畫面) | 點一下螢幕 |

- 平面 2D 模式看整個網頁;其他模式會自動找出網頁中的影片,只顯示影片本身
- YT 360:手機版 YouTube 不支援控制視角時,會自動改用嵌入式播放器開同一部影片
- 面板:最上排是資訊列(紅點從這裡開始),中間進度條,下排按鈕
  倒退10秒 / 播放暫停 / 快進10秒 / 音量－ / 音量＋ / 模式;看著約 1.2 秒觸發
- 2D / 左右3D 模式沒開面板時,點一下螢幕 = 播放 / 暫停
- 長按 = 把目前方向設為正前方(VR180 / 360),以及把目前角度當成「平視」(躺著看時)
- 返回鍵 = 回到 2D 模式

**藍牙遙控器 / 搖桿(VR 模式)**
- 左 / 右:倒退 / 快進 10 秒
- 播放鍵:播放 / 暫停;中鍵 / A:同點一下螢幕
- 上 / 下:音量

## 編譯
方法 A:GitHub Actions(不用裝 Android Studio)— 上傳整個資料夾到 GitHub,
Actions 會自動編譯,在 Artifacts 下載 APK。
方法 B:Android Studio 開啟此資料夾 → Build → Build APK(s)。

## 已知限制
- 網頁文字框要在 2D 模式點,VR 模式中無法打字
- 控制面板直接控制網頁中的影片;少數把影片放在內嵌框架中的網站會改用模擬點擊
- Netflix 等 DRM 影片會是黑畫面
- Google 帳號登入在 WebView 會被擋
