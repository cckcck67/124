# VR 網頁播放器 (Android)

把網頁影片畫面切成左右兩份,放進 VR 盒子觀看。

## 架構
網頁 WebView → 私有虛擬螢幕 (VirtualDisplay + Presentation) → OpenGL 材質
→ 2D 模式畫一份 / VR 模式左右各一份(眼距、鏡片校正可調)

## 操作
**2D 模式(一開始)**:像一般瀏覽器用手指操作。上方輸入網址或關鍵字,
`yt 關鍵字` 直接搜尋 YouTube,或按「YouTube」直接開啟。
點網頁裡的文字框(例如 YouTube 搜尋框)會跳出輸入視窗,可用手機鍵盤打字。
下方滑桿調「眼距」「鏡片校正」(會記住)。
建議先讓影片進入網頁的全螢幕播放,再按「VR」。

**VR 模式**
- 紅點游標:轉頭時才出現,頭不動約 2.5 秒自動隱藏,不擋畫面
- **低頭(約 20 度)= 叫出控制面板**,抬頭就收起來
  - 上排進度條:看著想跳到的位置不動約 1.5 秒 = 跳轉
  - 下排按鈕:倒退10秒 / 播放暫停 / 快進10秒 / 音量－ / 音量＋ / 游標置中 / 離開VR
  - 看著按鈕約 1.2 秒就會觸發(按鈕會慢慢填滿),音量鍵繼續看著會一直調整
  - 全程不用打開 VR 盒子點螢幕
- 點螢幕一下(盒子上的觸控鈕)= 在游標處點擊;游標隱藏時第一下只會叫出游標
- 點兩下 = 在游標處雙擊
- 長按 = 重新設定正前方(躺著看時很好用)
- 返回鍵 = 回到 2D 模式

**藍牙遙控器 / 搖桿(VR 模式)**
- 左 / 右:倒退 / 快進 10 秒
- 播放鍵:播放 / 暫停
- 中鍵 / A:在游標處點擊(面板打開時 = 按下看著的按鈕)
- 上 / 下:音量

## 編譯
方法 A:GitHub Actions(不用裝 Android Studio)— 上傳整個資料夾到 GitHub,
Actions 會自動編譯,在 Artifacts 下載 APK。
方法 B:Android Studio 開啟此資料夾 → Build → Build APK(s)。

## 已知限制
- 網頁文字框要在 2D 模式點,VR 模式中無法打字
- 控制面板直接控制網頁中的影片;少數把影片放在內嵌框架中的網站會改用模擬點擊
- Netflix 等 DRM 影片會是黑畫面
- Google 帳號登入在 WebView 會被擋
