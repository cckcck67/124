# VR 網頁播放器 (Android)

把網頁影片畫面切成左右兩份,放進 VR 盒子觀看。

## 架構
網頁 WebView → 私有虛擬螢幕 (VirtualDisplay + Presentation) → OpenGL 材質
→ 2D 模式畫一份 / VR 模式左右各一份(大小、位置、間距、翻轉角度可調)

## 操作
**2D 模式(一開始)**:像一般瀏覽器用手指操作。上方輸入網址或關鍵字,
`yt 關鍵字` 直接搜尋 YouTube。
點網頁裡的文字框(例如 YouTube 搜尋框)會跳出輸入視窗,可用手機鍵盤打字。
下方滑桿(會記住,旁邊顯示目前數值):
- 畫面大小:VR 畫面放大倍率,越大越填滿視野(邊緣會被裁掉)
- 畫面高低:往右 = 畫面往上移(VR 盒子下緣通常比較看不到)
- 左右間距:往左 = 兩眼畫面往中間靠(預設依手機螢幕寬度自動計算)
- 中間空隙:兩眼畫面中間加黑色空隙,避免一隻眼睛看到另一邊畫面造成雙影
- 翻轉角度:兩眼畫面沿垂直軸往相反方向翻轉,增加包覆感;太大容易頭暈

建議先讓影片進入網頁的全螢幕播放,再按「VR」。

**VR 模式**
- 平常畫面上沒有任何游標或按鈕
- **低頭(約 30 度)= 叫出控制面板和紅點游標**,抬頭就收起來
  - 紅點從面板最上排的資訊列開始(不能點的空位),再往下看才會選到東西
  - 中間進度條:看著想跳到的位置不動約 1.5 秒 = 跳轉
  - 下排按鈕:倒退10秒 / 播放暫停 / 快進10秒 / 音量－ / 音量＋ / 3D模式
  - 3D模式:2D → 左右3D → 上下3D 切換,用來看 YouTube 上的 3D 影片(搜尋「3D SBS」)
  - 看著按鈕約 1.2 秒就會觸發,音量鍵繼續看著會一直調整
- 點螢幕一下(盒子上的觸控鈕)= 播放 / 暫停;面板打開時 = 按下看著的按鈕
- 長按 = 把目前的頭部角度當成「平視」(躺著看時用)
- 返回鍵 = 回到 2D 模式

**藍牙遙控器 / 搖桿(VR 模式)**
- 左 / 右:倒退 / 快進 10 秒
- 播放鍵 / 中鍵 / A:播放 / 暫停(面板打開時 = 按下看著的按鈕)
- 上 / 下:音量

## 編譯
方法 A:GitHub Actions(不用裝 Android Studio)— 上傳整個資料夾到 GitHub,
Actions 會自動編譯,在 Artifacts 下載 APK。
方法 B:Android Studio 開啟此資料夾 → Build → Build APK(s)。

## 已知限制
- 網頁文字框要在 2D 模式點,VR 模式中無法打字
- 控制面板直接控制網頁中的影片;少數把影片放在內嵌框架中的網站會改用模擬點擊
- Netflix 等 DRM 影片會是黑畫面
- Google 帳號登入在 WebView 會被擋
