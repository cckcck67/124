# VR 網頁播放器 (Android)

把網頁影片畫面切成左右兩份,放進 VR 盒子觀看。

## 版本
- **1.0 自用完整版**:已定版保存(標籤 `v1.0`),內容見 [docs/releases/v1.0.md](docs/releases/v1.0.md)
- **2.0 研究 / 進化版**:進行中,方向與候選項目見 [docs/VERSIONS.md](docs/VERSIONS.md)

## 架構
網頁 WebView → 私有虛擬螢幕 (VirtualDisplay + Presentation) → OpenGL 材質
→ 2D 模式畫一份 / VR 模式左右各一份(大小、位置、間距可調;2D曲面模式是圍著自己的弧形巨幕)

## 操作
**首頁(開啟 App)**:功能選單,直式、橫式都可以用(跟著手機方向)。
- 網頁瀏覽 / 空中遊覽 / 我的影片 / 編輯旅程(即將推出)
- 右上角「⚙ 設定」:畫質(1080p / 1440p 預設 / 4K)、Google 金鑰、檢查更新;以後的設定都放這裡

**網頁瀏覽**:像一般瀏覽器用手指操作,直式、橫式都可以,網頁填滿整個螢幕;轉向時只重新排版、網頁不會重新載入。
網頁文字固定 100% 大小,不跟系統字型放大(避免排版擠在一起、字被切掉)。
網址列由左到右:「←」上一頁(沒有上一頁就回首頁)、「首頁」、網址輸入框、「★」書籤、「VR」。
輸入網址或關鍵字後按鍵盤的 Enter / 前往鍵,`yt 關鍵字` 直接搜尋 YouTube。網址列平常收起,不擋網頁:
網頁已在最上面時,再用手指往下拉一次才會出現;往下捲或輸入新網址後自動收起。
網址列的「★」= 書籤:點一下開啟、「加入目前網頁」收藏、長按可改名稱 / 網址或刪除。
點網頁裡的文字框(例如 YouTube 搜尋框)會跳出輸入視窗,可用手機鍵盤打字。
網頁可以用雙指放大縮小(網頁禁止縮放的也會強制開放)。建議先讓影片進入網頁的全螢幕播放,再按「VR」。

**我的影片**:「＋ 加入影片」從手機選擇影片(可多選),之後點一下就播放、長按從清單移除(不會刪檔案)。
播放時按「VR」,左右3D、VR180、上下VR 會依影片比例自動判斷。

**VR 模式**(一律橫式):按「VR」後畫面中央倒數 5 秒,這段時間把手機放進盒子、看正前方,數完自動置中。
進入時依影片比例自動選模式(約 2:1 → VR180,約 1:1 → 上下VR),
猜錯可用面板「模式」改。想要包圍感的 2D 影片,在「模式」選「2D曲面」(設定分開存,調一次就好)。

**空中遊覽(2.0 試作)**:首頁「空中遊覽」→ 選目的地,從遠處朝地標直線慢慢滑行,到附近停住懸停(不繞圈,比較不會暈)。
進入 VR 自動切到「環顧」,轉頭控制看的方向;「←」或返回鍵回目的地選單。
VR 面板是空中遊覽專用的:坐姿、暫停/繼續、重飛、換角度(換一個方向接近,畫面會先變黑再變亮)、置中、設定。
設定也和影片分開存:轉頭比例(轉頭時景物跟著跑就調小)、飛行速度、飛行高度,以及畫面大小、高低、間距等。
VR 面板第一層:坐姿/躺平、暫停、換角度、降落/起飛、飛快－/＋、飛高－/＋、置中、設定;資訊列顯示目前的速度與高度。
2D 畫面(沒戴 VR):手指拖動、縮放、旋轉 3D 地圖時自動飛行先停住,按「回到航線」繼續;下方控制列有暫停、換角度、降落、地圖、目的地。
目的地選單或控制列的「地圖」:拖動、縮放地圖,讓中間的紅色十字對準想去的地方(點一下也會移過去)→「從這裡起飛」或「存成地點」(綠色按鈕,✕ 按兩下刪除)。
有啟用 Elevation API 時會依地面高度調整飛行高度;沒有就當作接近海平面(山區可能太低)。
**降落**(VR 面板或 2D 控制列):按「降落」,畫面淡出淡入,站在地標附近的 Google 街景裡(2D 時手動移動過地圖,就降落在畫面中間的地方);VR 轉頭環顧,2D 用手指拖動、點地上箭頭往前走;按「起飛」回到空中。
**散步**:在地圖上選地點時按「散步(街景)」,直接進到那裡的街景。
**街景散步**:降落後 VR 面板換成散步按鈕:前進、後退(往臉朝的方向沿路走一步)、自動散步(每幾秒自動往前走,再按停止)、走快－/＋、回降落點、起飛;資訊列顯示目前的路名。2D 控制列也有前進、自動散步、回降落點。
Google 地圖出錯時(例如金鑰的專案沒有綁定帳單),畫面下方紅框會用中文說明原因。
會由近到遠(300 公尺 → 5 公里)找街景,都沒有才顯示「無法降落」。
需要自己的 Google 金鑰(啟用 Maps JavaScript API),在「⚙ 設定」或空中遊覽頁面輸入,只存在手機裡。

**YouTube VR 影片(用 YouTube App 播放)**:YouTube 用手機版身分瀏覽(正常手機排版)。
打開 360 / VR180 影片時,App 在背景向 YouTube 確認是 VR 影片;按影片的全螢幕,就自動改用 YouTube App
從同一個時間點全螢幕播放(App 裡的影片先暫停),在 YouTube App 按眼鏡圖示就能放進 VR 盒子看。
也會請 YouTube App 播完自動關閉、回到這個 App(要看 YouTube App 版本是否支援;不支援時用多工鍵切回)。
App 內建的網頁元件裡,YouTube 的 VR 影片轉動範圍受限、畫面會跳動,所以 VR 影片交給 YouTube App。
一般影片照舊在 App 裡看,按 VR 用平面模式;全螢幕和一般瀏覽器一樣,不會自動轉向或切換。

控制面板和紅點游標依姿勢叫出,頭轉回正前方就收起來:

| | 坐姿 | 躺平 |
|---|---|---|
| 2D、左右3D | 低頭約 50 度,面板在下方 | 抬頭約 20 度,面板在上方 |
| VR180、上下VR | 低頭約 50 度,面板在下方 | 抬頭約 25 度,面板在上方 |

- 面板由靠近畫面中央往外:空白列(紅點從這裡開始)→ 進度條 → 按鈕 → 資訊列
- 按鈕:坐姿/躺平 / 音量－ / 音量＋ / 快進10秒 / 模式 / 置中 / 設定,看著約 1.2 秒觸發
- 坐姿/躺平:切換後自動開始置中倒數,倒數時看著新姿勢的正前方
- 置中:倒數 3 秒,期間看想要的正前方,數完就以那個方向為準(躺著看天花板也可以)
- 音量、快進10秒持續看著會一直重複
- 模式:拉出選項列,往外看著想要的模式即可選取

| 模式 | 用途 |
|---|---|
| 2D | 一般影片 / 網頁 |
| 左右3D | 左右並排的 3D 影片(YouTube 搜尋「3D SBS」) |
| VR180 | 左右兩個半球的 VR 影片,轉頭可上下左右看,真正立體 |
| 上下VR | 上下兩個攤平全景圖的 VR 影片(上半給左眼),轉頭可上下左右看,真正立體 |

**設定**(面板上的按鈕):每項有 − / +,看著會一直調整,邊看邊調不用拆盒子;
**每個模式各自記住一組數值**,只列出目前模式用得到的項目;抬頭收起面板就離開設定頁。
- 2D:畫面大小、畫面高低、左右間距、中間空隙、面板距離、速度
- 2D曲面:曲面弧度、曲面大小、上下彎曲、邊緣拉伸、畫面高低、左右間距、中間空隙、面板距離、速度
- 左右3D:2D 的設定 + 曲面弧度(0 = 平面)、曲面大小、上下彎曲、邊緣拉伸
- VR180、上下VR:VR視野、左右間距、中間空隙、面板距離、速度

| 設定 | 作用 |
|---|---|
| 左右間距 | 兩眼畫面往中間靠(−)或往外(+),讓畫面中心對準鏡片中心;看遠處調到最輕鬆 |
| VR視野 | 轉頭時景物會反方向跑 → 調大;景物黏著臉跟著轉 → 調小;調到景物固定不動 |
| 中間空隙 | 兩眼中間的黑條,剛好看不到另一邊畫面即可,越小越自然 |
| 面板距離 | 面板有雙影時調,+ = 面板看起來較近 |
| 畫面大小 / 高低 | 平面畫面放大倍率與上下位置 |
| 曲面弧度 | 弧形巨幕左右張開的角度;螢幕固定在空間中,轉頭可看左右(左右3D 為 0 = 平面) |
| 曲面大小 | 和螢幕的距離:1.4 倍站在圓心,調大 = 走近螢幕,螢幕變大、上下黑邊變少,要轉頭才看得到兩端 |
| 上下彎曲 | 0% = 圓柱;調大螢幕上下也往自己彎(像半球幕),補滿上下黑邊,四角會稍微變形 |
| 邊緣拉伸 | 中間維持比例,越往兩邊拉得越寬,螢幕往兩側加長;人物在中間不變胖 |
| 速度 | 播放速度 0.5x / 1x / 1.5x |

- 沒開面板時,點一下螢幕 = 播放 / 暫停
- 長按 = 立刻把目前方向設為正前方(同「置中」,不用倒數)
- 返回鍵 = 回到 2D 模式

**藍牙遙控器 / 搖桿(VR 模式)**
- 左 / 右:倒退 / 快進 10 秒
- 播放鍵:播放 / 暫停;中鍵 / A:同點一下螢幕(面板打開時 = 選取看著的項目)
- 上 / 下:音量

## 效能
- 有變化才重畫:新影片畫面、轉頭(VR180 / 上下VR)、面板或倒數更新時才重畫,暫停或靜止時幾乎不耗電
- 頭部感應器在背景執行緒處理(約每秒 100 次),不佔用網頁與面板所在的主執行緒

## 更新
App 開啟或回到 App 時(最多每 30 分鐘一次)會自動檢查 GitHub 上有沒有新版本,有的話詢問是否更新,
按「更新」會下載並開啟系統安裝畫面,和用瀏覽器下載後點開安裝一樣(第一次要允許「安裝未知應用程式」)。
APK 使用固定簽章,新版直接安裝覆蓋即可,書籤和設定都會保留。

## 編譯
GitHub Actions 每次 push 都會自動編譯,並把 APK 與 version.json 發佈到 Releases 的 `latest`。
也可以用 Android Studio 開啟此資料夾 → Build → Build APK(s)。

## 已知限制
- 網頁文字框要在 2D 模式點,VR 模式中無法打字
- 控制面板直接控制網頁中的影片;少數把影片放在內嵌框架中的網站會改用模擬點擊
- Netflix 等 DRM 影片會是黑畫面
- Google 帳號登入在 WebView 會被擋
