# 整人聊天(看護陳姐)使用說明

偽裝成「LINE 好友捷徑」的聊天畫面。外觀照 LINE 截圖量出來的大小、顏色製作,
所有對話都可以自己編輯,拿來開玩笑用。和 VR網頁播放器是兩個不同的 App,可以同時安裝。

- 下載:Releases 中「整人聊天」的 [`PrankChat.apk`](https://github.com/cckcck67/124/releases/download/chat-latest/PrankChat.apk)
- 桌面名稱:**看護陳姐**;圖示:白色圓角方塊、圓形佛像、下方深藍色對話小圓章(和 LINE 捷徑一樣)
- 新版直接安裝覆蓋即可,已經編好的對話會保留

## 怎麼用

### 打開與離開
| 動作 | 結果 |
|---|---|
| 點桌面「看護陳姐」 | 直接進入上次看的聊天(第一次是「看護陳姐」) |
| 左上「<」或手機返回鍵 | 打開真的 LINE(停在 LINE 上次的畫面),這個 App 關掉 |
| 多工畫面 | 看不到這個 App |

### 管理選單(只有自己知道):長按上方名字
- 🔒 **鎖定 / 解除鎖定**:給朋友看之前先鎖定,點訊息、「＋」都不會跳出編輯畫面
- 📝 **批次新增對話**(見下方寫法)
- 🧰 **編輯工具**:切換傳訊息的身分、傳貼圖、加日期、改名稱 / 公告 / 大頭貼、成員、背景圖片
- ✂ **從截圖剪貼圖 / 頭像**
- 😆 **貼圖庫**:點一張就傳送
- 💬 **切換聊天 / 所有聊天**:可以有很多個聊天,點一下切換;長按編輯;「＋」新增
- ⇩ **匯入 LINE 聊天記錄**
- ⚙ **設定**:我的名字(匯入、批次新增時用來認出自己)
- 🗑 **清空所有聊天的對話**(聊天、大頭貼、貼圖庫會保留)

### 編輯訊息
- **點訊息**:改內容、誰說的、種類(文字 / 貼圖 / 照片 / 通話)、時間、已讀文字;上移、下移、在下面插入訊息 / 日期 / 批次新增、刪除
- **點日期**:改文字(也可以寫「小明已收回訊息」這類置中文字)
- **點上方名字**:改名稱、大頭貼、群組人數「(98)」、公告、是不是群組
- **輸入框送出** = 用自己的身分;**長按送出鍵** = 用對方的身分
- 群組的「已讀」會自動寫成「已讀 N」,也可以自己改

### 批次新增對話
一行一則訊息,一次貼上一整段:

```
--- 8月3日 週一
20:16 我: 大姐，媽媽今天吃飯還可以嗎？
20:21 對方: 阿印，還可以啦，今天有吃完
--- 8月7日 週五
對方: 阿印，媽媽今天一直想看電視，不太想睡
我: 哈哈，那就讓她看一下，晚一點再休息
對方: [貼圖:1]
```

| 寫法 | 意思 |
|---|---|
| `我: 內容` | 右邊綠色(自己) |
| `對方: 內容` 或 `成員名字: 內容` | 左邊白色;群組寫新的名字會自動加成新成員 |
| `20:16 我: 內容` | 指定時間;沒寫時間就從上一則往後自動加 0~2 分鐘 |
| `--- 8月3日 週一` | 日期分隔 |
| `[貼圖]` / `[貼圖:2]` | 表情貼圖 / 貼圖庫第 2 張 |
| `[照片]`、`☎ 通話時間 3:59` | 照片、通話紀錄 |
| 沒有「名字:」的行 | 接在上一則後面(同一則訊息換行) |

### 從截圖剪貼圖 / 頭像
1. 管理選單 →「從截圖剪貼圖 / 頭像」→ 選一張 LINE 截圖(長截圖也可以)
2. 上方選「貼圖」或「頭像」;用手指拉一個框(要上下移動畫面時先按「✋ 捲動」)
3. 按「剪下」
   - 貼圖:藍色和雲朵背景自動去掉 → 存到貼圖庫(或馬上傳送);背景去不乾淨可以選「不要去背景」
   - 頭像:選這是誰的大頭貼(聊天、某位成員、自己)
4. 同一張截圖可以連續剪很多個,按「✕ 關閉」結束

### 匯入 LINE 聊天記錄
LINE 打開那個聊天 → 右上 ≡ → 其他設定 → 傳送聊天記錄 → 選「看護陳姐」,整段對話自動帶進來。
也可以先存成 .txt,再從管理選單「匯入」選檔案。支援 12 / 24 小時制、多行訊息、貼圖、照片、通話、收回訊息。
(Android 不讓其他 App 直接讀 LINE 的資料,這是 LINE 唯一開放的方式。)

### 和 LINE 一樣的小細節
- 捲動時上方浮出目前那一段的日期,停下 1.5 秒後收起;不在最底下時右下有「↓」
- 日期後面沒有訊息就不顯示(不會兩個日期疊在一起)

## 程式架構(給以後修改用)

| 檔案 | 內容 |
|---|---|
| `chat/src/main/assets/index.html` | 全部畫面與功能(HTML + JavaScript),依區塊分段:資料、聊天室、捲動日期、批次新增、貼圖庫、剪截圖、所有聊天、匯入 LINE、返回鍵 |
| `chat/src/main/java/com/cck/prankchat/MainActivity.kt` | WebView 外殼:存檔、選圖片 / 檔案、狀態列顏色、返回鍵、打開 LINE、接收 LINE 分享 |
| `chat/src/main/AndroidManifest.xml` | App 名稱、不顯示在最近使用、接收分享、可以找到 LINE |
| `chat/src/main/assets/buddha.jpg` | 看護陳姐的大頭貼 |
| `chat/src/main/res/drawable-xxxhdpi/ic_launcher_fg.png` | 桌面圖示前景;原稿在 `chat/icon-src/` |
| `chat/src/test/.../StartupTest.kt` | 啟動測試,每次編譯前先跑 |

- **資料**存在手機 App 資料夾的 `chats.json`(解除安裝才會刪掉)。
  資料有版本號 `ver`:改了資料格式或需要一次性處理(例如第 2 版清空所有對話)時,版本號加 1,在 `load()` 裡處理舊資料。
- **大小與顏色**:對照 LINE 截圖量出(手機寬約 393px):訊息文字 20.5px、時間 13.5px、頭像 31px、
  背景 `#8dacd8`、自己的泡泡 `#9de694`、日期 `#7692b9`,集中在 `index.html` 最上面的 CSS。
- **編譯發佈**:推送後 GitHub Actions(`.github/workflows/build.yml`)會檢查網頁語法、跑啟動測試、編譯,
  發佈到 Releases 的 `chat-latest`(VR 播放器是 `latest`,兩個分開)。版本號 1.0.編譯次數。
