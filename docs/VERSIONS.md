### 第一個研究項目:虛擬旅行(進行中)
- 對象:先鎖定長輩;身邊長輩先試看 YouTube 360 旅遊影片(暫不考慮版權)
- 構想:精選旅程(360 旅遊影片)、空中遊覽(Google 3D 城市)、家人的旅行回憶(自己拍的影片+語音註解)、長輩模式
- 街景:一張張照片、不連續,不當主角;可當「找地點」的工具
- **2.0.x 試作:空中遊覽**
  - 首頁「空中遊覽(試作)」→ 選目的地(台北101、京都清水寺、日月潭、富士山、巴黎鐵塔、紐約曼哈頓)
  - 繞著地標慢慢飛一圈,預設看向地標;進入 VR 自動切到「環顧」,轉頭控制看的方向;點兩下回目的地選單
  - 使用 Google Maps JavaScript API 的 3D 地圖,金鑰在 App 內輸入、只存在手機裡
  - 要驗證:小米9 流暢度(建議畫質 1080p)、免費額度、VR 裡的感受;目前單眼,立體深度之後再試
  - 第一次測試:金鑰可用、轉頭流暢;繞圈飛行會頭暈、轉頭畫面跟太多、畫質偏低(3D 模型本身的限制)
  - 改進:改成直線慢慢滑行+懸停、換角度時淡出淡入、空中遊覽專用面板與設定(轉頭比例、速度、高度)

  - 加入:在地圖上選地點(可存成自己的地點)、降落到街景 / 起飛
- YouTube VR(C 方案):平常用手機版;VR 影片在網址列出現「VR 播放器」按鈕,自己按才開上層官方播放器(可調轉頭比例);全螢幕不再自動轉向或切換
- 診斷紀錄:記錄 YouTube VR 轉頭的數據(要求角度、實際角度、邊界事件),設定頁「診斷紀錄」可分享或複製給 Claude;VR 面板設定多「邊界學習」開關

### 2.0 介面改版
- 首頁改成功能選單(網頁瀏覽、空中遊覽、我的影片、編輯旅程〔即將推出〕),右上角「⚙ 設定」
- 直式 / 橫式跟著手機方向;VR 一律橫式。網頁放在正方形虛擬螢幕中,轉向只重新排版、不重新載入
- 畫質從網址列移到設定頁;設定頁另有 Google 金鑰、檢查更新
- 我的影片:從手機選影片播放(本機小伺服器提供,支援拖進度條),VR 自動判斷格式
